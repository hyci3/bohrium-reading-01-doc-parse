# 多栏顺序与视觉复核

## 1. 坐标到阅读顺序

提取器的流顺序只是原始观察，不能直接作为正文顺序。`extract` 保留 `raw_blocks` 的原始编号、bbox 与 `source_order`，再通过独立 `reading_order` 生成页内和全局顺序。稳定证据 ID 为 `p%04d-b%04d`，按物理页和页内最终顺序生成。

默认流程不使用整页 `(y0, x0)` 作为一种正确的多栏读法。`--order naive` 仅用于对照，输出中明确标记 `mode=naive`，不应作为最终科学阅读产物。

## 2. 当前几何规则及限制

以下参数是可审阅的开发默认值，不是对所有论文有效的版式定理：

1. 页眉页脚候选由跨页重复文本和页面边距识别；孤立页码单独保留为 footer。保留原文字，不从磁盘证据中删除。
2. 宽块若覆盖至少页面宽度的 68%，或左边不超过 33% 且右边越过 62%，被视作跨栏候选。
3. 区域内按左边缘及 2% 页宽的水平间隙寻找栏簇，支持至多三栏。候选栏须有实际纵向重叠；证据不足回退为单栏。超过三个不稳定栏簇时保留坐标回退，将 `ambiguous=true` 并发出页图复核警告，不能强制分配栏位。
4. 栏内按纵向及横向坐标排序；跨区域按从上到下，区域内先左栏再右栏。
5. 狭窄公式、脚注和小字可能与宽正文在纵向重叠。重叠达到较小区块高度的 15% 时，放到同一混合区域，不能因其 x 坐标或 y 起点稍晚就推到页尾。
6. 标题、题注、公式和参考文献结合编号、文本模式及可用字体特征分类。复杂视觉结构仍待复核，不把这种分类称为完整语义恢复。

这些规则已针对实际单栏论文中重叠公式出现过误归属，故保留混合区域。若模型察觉明显错序，应检查渲染页和原始 bbox，而不是按语义猜排来掩饰算法不确定性。

## 3. 跨页关系

只有在页末有断词连字符，或下一页以小写字母开始且上一块未终止时，才建立 `continues_candidate` 候选链接。链接记录 `source`、`target` 和 `reason`，需要复核。

“上一页末尾无终止标点”不足以拼接两块。`New section...` 这样的大写新句不能和大写标题、列表或新章节仅凭状态自动并入。图表、脚注和参考文献也要防止误接。保留原块和原始文字，可在 Agent 检查页图后记录最终采用的关系。

## 4. 何时必须看图

- 双栏候选有跨越边界的文字、浮动图表、题注游离或多候选栏序；
- 页面上公式、脚注或文字坐标重叠；
- 页图文字与文本层不同、符号替换字符、OCR 或稀疏文本；
- 答案依赖具体图中曲线、颜色、点或子图语义；
- 表格合并单元格或复杂数学结构参与关键结论。

最多查看当前 selection 所列的少量相关页图。页面图片通常需与文本块共同核验，不把图像的可见范围当作整篇论文覆盖。

## 5. 对照与金标准

独立的人工金标准由完整区块的精确文本列表按页给出。例如 `tests/fixtures/two-column-gold.json` 是开发夹具，不是正式评测答案。运行：

```bash
python <skill-dir>/scripts/run.py evaluate-order --document <work>/document.json --gold <gold.json> --output <work>/order-report.json
```

报告按建立金标准的完整区块过滤页眉页脚。每页位置记录实际排名；对于所有期望区块对 `(i,j)`，实际位置反向即一个 inversion。`order_accuracy=(n(n-1)/2-inversions)/(n(n-1)/2)`，`document_exact_match` 要求所有金标准区块匹配且全部页面无逆序。

金标准文本缺失或出现重复歧义时退出 7，不计算伪精确改进分数。真实 PDF 复核至少保存原 PDF 标识、页图、naive/layout 结果与差异。没有独立可确认错误时，顺序不同不构成改进证据。简洁双栏样例和真实重叠公式样例均须通过，才能将相应改动视为本范围内的回归修复。

科学术语、数值、公式符号、表格列对齐及题注关系必须保留提取状态与限制，不因排序功能通过就声称高保真 OCR 或数学重建。
