# 多栏顺序与视觉复核

## 1. 坐标到阅读顺序

提取器的流顺序只是原始观察，不能直接作为正文顺序。`extract` 保留 `raw_blocks` 的原始编号、bbox 与 `source_order`，再通过独立 `reading_order` 生成页内和全局顺序。证据 ID 为 `p%04d-b%04d`，按物理页和页内最终顺序生成，稳定性只限同一文档产物及其 `document_sha256`。重新分类或排序可能使物理块重编号；不得按相同 ID 尾号跨版本继承引文，也不得把旧游标用于新文档。

默认流程不使用整页 `(y0, x0)` 作为一种正确的多栏读法。`--order naive` 仅用于对照，输出中明确标记 `mode=naive`，不应作为最终科学阅读产物。

## 2. 当前几何规则及限制

以下参数是可审阅的开发默认值，不是对所有论文有效的版式定理：

1. 页眉页脚候选由跨页重复文本和页面边距识别，自动 `table` 候选不参与重复页边文本统计。除完全相同的重复文本外，带物理页码前缀的 running header 只有在至少三个不同物理页匹配时才可按保守规则归类；该归类不改变 `raw_text`，也不把 `System` 等非数字单词当作页码。正文区域的纯数字、同一页同一边距带内的多个孤立数字块均保留在主阅读流中；后一种情况须发出警告。页边唯一数字候选仍可能按旧规则归类为页眉或页脚，但这不是对其页码语义的普遍证明。
2. 宽块若覆盖至少页面宽度的 68%，或左边不超过 33% 且右边越过 62%，被视作跨栏候选。
3. 区域内按左边缘及 2% 页宽的水平间隙寻找栏簇，支持至多三栏。候选栏须有实际纵向重叠；证据不足回退为单栏。超过三个不稳定栏簇时保留坐标回退，将 `ambiguous=true` 并发出页图复核警告，不能强制分配栏位。
4. 栏内按纵向及横向坐标排序；跨区域按从上到下，区域内先左栏再右栏。
5. 狭窄公式、脚注和小字可能与宽正文在纵向重叠。重叠达到较小区块高度的 15% 时，放到同一混合区域，不能因其 x 坐标或 y 起点稍晚就推到页尾。
6. 标题、题注、公式和参考文献结合编号、文本模式及可用字体特征分类。题注须以标签、编号及明确的 `:`、`.` 或相应全角分隔符开始，避免把 `Table 2 shows...`、`Figure 5 presents...` 一类正文引用判为题注。数字标题规则拒绝第二个词元仍为数字的表达，以及第二个词元为孤立 `x`、`×` 或 `*` 的乘法表达。字母编号的附录标题（`A.2`、`A.2.1`、`Appendix B`）同样参与分类，级别取编号中的点号数加一，使附录正文不再沿用 `References` 的章节路径。短语级（四个词以上）的标题若以 `.`、`?`、`!`、`;`、`:` 结尾，或第二个词元是 `of`、`and`、`the`、`for` 一类功能词，按正文处理：这类文本通常是编号列表句或被拆开的上标续行。同一位置的公式碎片（含 `U+0010`–`U+001F` 控制码、以公式编号片段开头且带运算符、或仅由少量字母与运算符组成）标为 `formula` 并附 `formula_fragment_unverified` 警告，要求引用前看页图，绝不冒充完整公式，也不冒充小节标题。对位于 `y0 >= 0.85 * page_height`、至少九个词且以 `.`、`!`、`?`、`。`、`！`、`？` 结尾的数字开头文本，保守保留为 body 并发出可能为脚注的警告，而不是声称已验证 footnote 类型。短脚注、分离的章节编号与标题仍可能误判；没有字体元数据时尤其如此，章节路径仅用于导航而非已验证的文章层级。
7. 自动 `table` 区块是提取器候选，不等同于已验证的表格。提取器给出 `rows` 时，区块文本按检测到的每一行各自成行、单元格以 ` | ` 分隔，并记录 `table_row_count`、`table_column_count` 与 `table_warning`，使上下行数值不再被压进同一句；这些行列数只描述提取器输出，不是原表尺寸。保留候选行的同时记录 `table_candidate=true`、`requires_visual_review=true` 与具体警告；表检测候选和失败原因写入页级 warnings，并按图像预算生成必要页图。原始文字块与自动候选 `rows` 是不同证据层，候选的行数、列数不得描述为原表尺寸，也不得据此推断多行表头、合并单元格或数值单元格归属。当前实现不能普遍恢复复杂表格或曲线、流程图中的真实语义关系，不得将 `find_tables()` 或可画的行列直接当作正确表格结构。
8. Poppler 回退路径只在同一 XML 行内依据实测间距、字号和下移量拼接可审计的下标；紧随标点只有在已审计下标之后且间距足够紧密时才拼接。两行浮动文本带采用保守几何拆分，保留原词、bbox、父文本、栏沟证据和警告。上述结果仍需按任务复核，不是 OCR，也不为 Poppler 自动发明表格候选。

这些规则已针对实际单栏论文中重叠公式出现过误归属，故保留混合区域。若模型察觉明显错序，应检查渲染页和原始 bbox，而不是按语义猜排来掩饰算法不确定性。

## 3. 跨页关系

只有在页末有断词连字符，或下一页以小写字母开始且上一块未终止时，才建立 `continues_candidate` 候选链接。链接记录 `source`、`target` 和 `reason`，需要复核。

“上一页末尾无终止标点”不足以拼接两块。`New section...` 这样的大写新句不能和大写标题、列表或新章节仅凭状态自动并入。图表、脚注和参考文献也要防止误接。保留原块和原始文字，可在 Agent 检查页图后记录最终采用的关系。

## 4. 何时必须看图

- 双栏候选有跨越边界的文字、浮动图表、题注游离或多候选栏序；
- 页面上公式、脚注或文字坐标重叠；
- 页图文字与文本层不同、符号替换字符、OCR 或稀疏文本；
- 答案依赖具体图中曲线、颜色、点或子图语义；
- 表格合并单元格或复杂数学结构参与关键结论。

最多查看当前 selection 所列的少量相关页图。页面图片通常需与文本块共同核验，不把图像的可见范围当作整篇论文覆盖。

## 5. 对照与金标准

独立的人工金标准由完整区块的精确文本列表按页给出。例如 `tests/fixtures/two-column-gold.json` 是开发夹具，不是正式评测答案。运行：

```bash
python <skill-dir>/scripts/run.py evaluate-order --document <work>/document.json --gold <gold.json> --output <work>/order-report.json
```

报告按建立金标准的完整区块过滤页眉页脚。每页位置记录实际排名；对于所有期望区块对 `(i,j)`，实际位置反向即一个 inversion。`order_accuracy=(n(n-1)/2-inversions)/(n(n-1)/2)`，`document_exact_match` 要求所有金标准区块匹配且全部页面无逆序。

金标准文本缺失或出现重复歧义时退出 7，不计算伪精确改进分数。真实 PDF 复核至少保存原 PDF 标识、页图、naive/layout 结果与差异。没有独立可确认错误时，顺序不同不构成改进证据。简洁双栏样例和真实重叠公式样例均须通过，才能将相应改动视为本范围内的回归修复。

科学术语、数值、公式符号、表格列对齐及题注关系必须保留提取状态与限制，不因排序功能通过就声称高保真 OCR 或数学重建。

## 6. 原文、几何修正与 XML 恢复

普通正文、页眉和页脚均初始化 `source_text` 字符串；`raw_text` 保留提取器原始块文本，`source_text` 是当前阅读器输出文本。`source_text_before_adjustments` 特指读取器在几何修正前重建的文本，不是原始 XML 字面字节。几何修正事件须保留原词、坐标、阈值、原因和必要警告；分类、排序或上下文选择不得删除原始文字、源哈希、原始几何与这些审计字段。修正后的文本仍不自动取得印刷字形、上下标语义或单元格归属的验证状态。

Poppler XML 恢复只处理 XML 1.0 不允许的 C0 控制码，原码点、源 XML 路径与哈希随 `extraction_recovery` 保存，原始 XML 不被改写。其他 malformed XML、无效 UTF、未转义 `&` 和保留标记冲突仍须失败，不得扩大恢复范围。保留下来的控制码点不证明其印刷字形含义，也不是 OCR 结果；相关页面和索引须保留风险信息，任务依赖这些字符时应另行复核。

渲染页图只提供复核材料。图像存在、渲染成功或哈希一致均不能由 helper 自动转换成“已看图”；应由 Agent 直接读取图像后另行记录实际观察、图像与 PDF 哈希、文档版本、后端和适用范围。该观察不自动批准自动表候选，也不证明整篇论文或全部数值单元格已经视觉核验。
